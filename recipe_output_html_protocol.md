# Recipe Output — HTML Cooking Sheet Protocol (v2.0, 2026-10-30)

> The HTML cooking sheet is the jins-kitchen print view. Hand-built HTML sheets are retired (v1.3 and earlier): two HTML layouts are how the printed formats drifted apart.

When HTML is named ("export to HTML", "generate the HTML"), point Jin to `jins-kitchen.netlify.app/#/print/meal/<slug>` (or `/print/dish/<slug>`); the browser saves it as HTML or PDF. Its content and page plan are `recipe_output_print_protocol.md`. A recipe that is not yet saved has no print view: save it first (data protocol), then print.
